# 2026-10-22 재점검 결과

학습·저장 모델·새 API 범위의 추가 결함을 수정한 뒤 재점검을 통과했다. 기존 프론트엔드의 새 API 연결과 실제 브라우저 동작은 다음 작업 범위다.

## 발견·수정한 문제

| 문제 | 기존 동작 | 수정 후 |
|---|---|---|
| 미지원 카테고리 | 정상 예측 반환 | 학습 카테고리 범위를 확인해 422 반환 |
| 잘못되거나 손상된 실험 보고서 | 잘못된 준비 상태 200 또는 내부 오류 500 | 상태·예측에 같은 검증을 적용해 503 반환 |
| 누락된 모델 해시·파일 | 완전한 준비 판정 보장 안 됨 | 선택 모델에 필수인 파일과 해시를 강제 검증 |
| 폐기 표시 누락 | 과거 앙상블 재로딩 가능 | 과거 앙상블 로딩 자체를 차단 |
| 실험 ID 규칙 차이 | 학습 후 API에서 사용할 수 없는 ID 허용 | 같은 검증 함수 적용 |
| 작은 MLP 학습 자료 | 배치가 모두 생략될 가능성 | 자료 크기에 맞는 배치와 실제 학습 검사 |

미지의 추가 입력과 소수 조회수·댓글 건수도 명시적으로 거부한다. 현재 API가 지원하는 범주는 Entertainment, Music, News, Lifestyle, Education이다.

## 실제 검증

- 기존 설치 환경과 잠금 파일로 만든 새 가상환경에서 테스트 38개 통과.
- 실제 전체 데이터에서 분할 간 영상 중복 0건, 라벨 확인 시점, 피처 허용 목록과 분할 기록의 무결성 확인.
- 같은 설정 재학습 후 모델 8종의 Test 예측 4,986건이 초기 실행과 오차 1e-6 이내로 일치.
- 저장 모델 8종의 재로딩 예측, 새 API 상태·분류 응답 200, 폐기 모델 차단 확인.
- 선택 모델 MLP+Embedding의 Test AUC 0.8128, F1 0.6653 유지. 재학습은 API·산출물 검증 수정 후의 재현 확인이며 새로운 성능 탐색이 아니다.
- 테스트 도구의 HTTP 클라이언트 전환 예정 경고 1개는 남아 있다. sklearn MLP의 고정 반복 횟수 수렴 경고도 기존 제한으로 기록했다.

## 판단과 후속 범위

현재 확인한 학습·새 API 변경 범위에서는 다음 화면 연동을 막는 결함이 남아 있지 않다. 서비스 전체의 완료 판정은 아직 할 수 없다. 기존 화면에는 초기 시각·순위 입력이 없고, 예시 예측·예상 지속 시간·신뢰구간·과거 성능 값이 남아 있다.
