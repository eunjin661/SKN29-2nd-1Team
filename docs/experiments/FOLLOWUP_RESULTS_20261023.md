## 캠페인 계산의 확인 범위

예산 1,000,000원, CPM 10,000원, CTR 1%, 클릭 대비 CVR 2%를 입력한 경우 노출 100,000 / 클릭 1,000 / 전환 20 / CPA 50,000원이다. 전환 0일 때 CPA는 null·계산 불가다. 극소 양수 전환은 0으로 잘라내지 않으며 화면에는 `0.01 미만`으로 표시할 수 있다.

카테고리 예산 배분은 100%를 요구하고 Decimal과 최대 잔여 방식으로 정수 원 총합을 보존한다. 예산 1원, 33.33/33.33/33.34%는 0/0/1원이다. 요청 중 중복 전송을 막고 입력 수정·이동 시 취소한다. CSV에는 입력 가정·단위·자료 출처·결과가 들어간다. 실제 광고 성과를 측정한 결과나 수익률 예측이 아니다.
