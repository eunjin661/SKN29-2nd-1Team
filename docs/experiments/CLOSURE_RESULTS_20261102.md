# TrendIt 구버전 API·문서 정합성 마감 — 2026-11-02

상태: **로컬 검증 완료·main 반영 준비**. 사용자가 승인한 범위는 남은 정합성 정리와 개인 main 직접 반영이다. 다음 ML 실험·배포·시연 제작은 진행하지 않았다.

## 변경과 원인

주요 화면은 검증된 T0 API를 사용했지만 서버는 구버전 모델·예측·샘플 영상 라우터도 등록했다. `/model/final-summary`의 고정 AUC 0.895124, 고정 중요도, 임의 신뢰도와 가상 시퀀스가 정상 API처럼 노출되는 사각지대였다. 같은 종류의 `/video/*` 샘플 3개도 함께 폐기했다. 현재 화면에서는 이 구버전 경로를 호출하지 않는다.

- **13개 기존 주소**: HTTP 410·ok=false·폐기 사유·현재 경로만 반환. 예측/성능/중요도/신뢰도/샘플 데이터를 반환하지 않는다. 이전 요청이 잘못된 JSON이어도 모델이나 예시 결과를 실행하지 않는다.
- **기본 OpenAPI 38→25 경로**: 현재 계약만 표시한다. `/api/status`도 현재 경로와 폐기 목록을 분리한다. 주소 삭제에 따른 조용한 404나 새 모델로의 자동 입력 변환 대신 명시적 종료 안내를 사용한다.
- **과거 소스 네 모듈**: `backend/api/routes`에서 제거하고 [원본 기록](legacy_api_archive_20261102/README.md)으로 옮겼다. 파일·정규화 Git blob 해시를 모두 보존했다. 과거 가중치는 기존 위치에 두되 API 실행 경로는 없다.
- **문서**: README·현재 근거 원장에는 현재 API와 마감 상태를 반영했다. 과거 계획·PR 초안·공개 준비 문서는 당시 기록임을 명시하고 최신 결과를 연결했다.

- 폐기 경로·무로딩·기본 문서·현재 API 분리 **19개 회귀 사례** 통과. 기존 4개 private-loader 검사는 새 공개 API 계약 검사로 교체했다.
- 전체 백엔드 **122개**, 실제 API를 연결한 전체 브라우저 **49개** 통과. 실패·skip·flaky 0, retries 0. HTTP 테스트 도구 전환 예정 경고 1개는 유지한다.
- 전체 lint 오류/경고 0, npm audit 0, 빌드 통과. 프론트 소스·의존성은 이번 작업에서 바꾸지 않았다.
- 실제 평가 API 200·기존 선택 모델/임계값 유지. 현재 중요도는 `not_computed`·빈 목록을 반환한다. 기존 ML 소스 8개 해시를 유지했으며 로컬 새 학습이나 성능 튜닝은 하지 않았다.
