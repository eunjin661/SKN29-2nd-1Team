# T0 누수 방지 평가·실제 관측 분석·가정 기반 계산과 재현 검증

최초 진입 예측에 최종 지속 시간 등 미래 정보가 포함되고, API 실패나 미구현 분석이 고정 수치로 정상 결과처럼 표시되던 문제를 수정합니다. 실제 T0 관측값과 Train 통계만 사용하는 평가·추론 경로를 만들고, 관측 분석 및 사용자 가정 계산의 적용 범위를 일치시킵니다.

- 시간 분할·6시간 정답 확인·분할 사이 영상 중복 제거·입력 허용 목록으로 평가를 재구성합니다. 개인 MLP/TabNet 실험 원본의 출처를 보존합니다.
- 관측 분석·대시보드·첫 화면의 고정 집계와 과거 모델 설명을 실제 자료와 현재 실험에 연결합니다. 지표별 표본·제외·기간·출처를 표시합니다.
- 캠페인의 임의 ROI·위험도·자동 집행 판단을 명시적 예산/CPM/CTR/CVR 가정 계산으로 정리합니다. 결과와 입력 사본·CSV를 일치시킵니다.
- 기준 모델을 유지하며 5개 시드 변동과 2,000회 paired video bootstrap을 추가합니다. 기존 Test를 이용한 진단으로 표시합니다.
- 오류·시간 초과·늦은 응답·캐시·CSV·모바일·다크모드 경계를 검증하고 패키지 경고를 갱신합니다. 백엔드/브라우저 자동 검사 구성을 준비합니다.

검증: 백엔드 107개·전체 브라우저 49개 통과. 새 venv/node_modules의 별도 checkout에서도 백엔드 107개·기본 모드 브라우저 47개 통과. 8개 모델 재학습 후 39,888개 Test 점수 최대 절대차 0.0. 전체 lint 오류/경고 0, npm audit 전체/런타임 0, 빌드 통과. 배포용 15개 경로와 모바일 5개 경로 확인.

모델의 기준 Test AUC 0.8128/F1 0.6653·임계값 0.44는 유지합니다. 5시드 AUC 평균 0.8130·표본 표준편차 0.0013, 기준 시드 AUC 재표집 구간 0.8007~0.8237입니다. 시드 평균과 표본 구간을 구분하며, 실시간 운영 성능·외부 기간 일반화·교정 확률·광고 수익 개선을 주장하지 않습니다. HTTP 테스트 도구 경고 1개와 비선택 기준 모델의 수렴 안내는 기록에 남깁니다.
