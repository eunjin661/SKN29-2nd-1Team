# TrendIt 다음 우선순위 — 2026-11-02

구버전 API·문서 정합성 마감 이후에는 추가 개발을 계속하기보다 취업 준비에 바로 쓰는 자료를 먼저 정리한다. 아래 작업은 이번 마감 구현에 포함하지 않았으며 다음 선택을 위한 계획이다.

| 순위 | 작업 | 구체적인 산출물·완료 기준 |
|---|---|---|
| 1. 취업 준비 | 개인 기여와 문제 해결을 설명하는 짧은 시연 | 3분 안에 실제 T0 입력→검증 결과→누수/고정 API 정리 사례를 보여 준다. 팀 역할·개인 실험·후속 보완을 구분하고 근거 원장으로 연결한다. 영상 또는 대표 화면 구성으로 준비한다. |
| 2. 개발을 더 한다면 | 오탐·미탐의 원인 분석 | 고정 Test의 FP/FN을 카테고리·초기 조회수·진입 지연 구간별로 표본 수와 함께 정리한다. 대표 사례 5~10개와 운영상 가능한 사용 범위를 설명한다. Test를 본 뒤 같은 Test에서 최고 모델·임계값을 다시 선택하지 않는다. |
| 3. 다음 ML 검증 | 미리 고정한 추가 시간 구간 평가 | Train 통계·정답 확인 여유·영상 중복 제거를 각 분할에 다시 적용한다. 같은 Test의 5시드/재표집과 다른 기간의 평가를 구분해 기록한다. 새 자료가 없으면 과거 구간의 rolling 평가라는 한계를 명시한다. |
| 4. 외부 서비스 운영을 선택할 때 | 배포 환경·접근 범위·호출 제한·장애 감지 | 실제 공개 도메인과 YouTube 호출 비용/실패 정책에 맞춰 CORS·키 관리·요청 제한·관측성을 점검한다. 현재 로컬 교육용 범위와 구분한다. |
